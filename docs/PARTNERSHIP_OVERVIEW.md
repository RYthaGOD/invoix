## 🎯 What is Invoix?

**Invoix** is an enterprise-grade B2B invoice settlement platform on Solana. Businesses use Invoix to:

1. **Create invoices** → Stored securely with Arcium privacy
2. **Share payment links** → Customer receives URL or Blink
3. **Settle instantly** → On-chain payment in USDC/EURC/PYUSD/SOL
4. **Get proof** → Automatic cNFT receipt for accounting

---

## 💡 Integration Opportunity for Solflare

### What We're Proposing

| Feature | Description |
|---------|-------------|
| **In-Wallet Invoice Payments** | Users pay B2B invoices directly from Solflare |
| **Magic AI Support** | "Pay my invoice" natural language commands |
| **Push Notifications** | Alert users when they receive an invoice |
| **Invoice Inbox** | View pending invoices in wallet |

### User Experience

```
1. User receives invoice → Notification in Solflare
2. User opens invoice → Sees amount, due date, sender
3. User clicks "Pay" → Reviews transaction
4. User confirms → Done. cNFT receipt minted.
```
